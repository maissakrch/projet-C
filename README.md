# projet-C
### Présentation

Ce projet a pour objectif de créer une bibliothèque en langage C permettant de manipuler des nombres binaires de grande taille, appelés BigBinary.
Ces nombres ne sont pas limités par les types natifs du langage (int, long, etc.) et permettent d’implémenter des algorithmes avancés en travaillant uniquement sur des bits.

Le projet est organisé en plusieurs phases, allant des opérations de base jusqu’à une démonstration de RSA simplifié.

### Organisation du projet
bigbinary.h   // Déclarations des fonctions
bigbinary.c   // Implémentation de la bibliothèque BigBinary
main.c        // Programme de test et démonstration

### Fonctionnalités principales
#### Phase 1 – Opérations de base

Création de nombres binaires de taille arbitraire

Affichage des nombres

Comparaison de deux BigBinary

Addition binaire

Soustraction binaire (si A ≥ B)

#### Phase 2 – Algorithmes avancés

Décalages binaires (gauche et droite)

Calcul du PGCD binaire (algorithme de Stein)

Calcul du modulo

Multiplication égyptienne, basée sur des décalages et des additions

Exponentiation modulaire rapide

#### Phase 3 – RSA simplifié

Génération de paramètres fixes pour la démonstration

Chiffrement et déchiffrement RSA

Utilisation de l’exponentiation modulaire
